# 抖音电商运营专家 (Douyin E-commerce Operations)

> 基于 Hermes 飞书知识库的专业抖音电商运营方法论

## 简介

这是一个为 AI Agent 设计的抖音电商运营技能，涵盖店铺运营、直播带货、短视频营销、用户分层运营、货品管理等全链路能力。

## 功能模块

### 1. 店铺运营
- 店铺搭建与装修
- 商品上下架管理
- 客服话术优化
- 售后处理流程

### 2. 直播带货
- 直播策划方案
- 主播人设打造
- 直播话术设计
- 逼单成交技巧
- 数据复盘分析

### 3. 短视频营销
- 内容策划与选题
- 爆款脚本模板
- 发布时间优化
- 投流策略

### 4. 用户分层运营
- 粉丝画像分析
- 私域引流话术
- 复购激活策略
- VIP 用户维护

### 5. 货品管理
- 选品策略
- 价格带规划
- 库存周转优化
- 货盘组合设计

## 使用方式

### 在 Hermes 中使用

```
# 触发词
抖音电商运营、直播带货、短视频营销、店铺运营、货品管理
```

### 作为独立工具使用

加载 `SKILL.md` 文件即可获得完整的运营方法论。

## 设计理念

本技能基于实战运营经验总结，强调：

1. **数据驱动** - 每个决策有数据支撑
2. **用户视角** - 从用户需求出发设计策略
3. **落地执行** - 提供具体可操作的脚本和话术
4. **持续迭代** - 根据数据反馈优化
