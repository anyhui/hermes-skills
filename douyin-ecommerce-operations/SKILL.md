# 抖音电商运营专家 Skill

## 概述

本 Skill 基于王总飞书知识库中的抖音运营资料整理而成，包含**店铺运营白皮书**、**营销宝典**、**供销平台指南**等核心方法论，可帮助完成：

- 店铺运营策略制定与诊断
- 货品分层与组货策略
- 用户分层运营（新客/粉丝/会员）
- 直播间运营方案
- 短视频内容策略
- 营销活动策划
- 数据分析与优化建议

## 一、店铺运营核心模型

### 店铺四大价值定位

| 价值维度 | 定义 | 运营要点 |
|---------|------|---------|
| **货品阵地** | 品牌商品运营核心阵地 | 覆盖自播、达播选品，大促爆发及日销场景 |
| **流量中枢** | 流量串联、承接、用户自主访问载体 | 打通各场景进店路径，承接私域流量 |
| **品牌阵地** | 种草-成交全流程载体 | 品牌号种草蓄水，店铺转化成交 |
| **用户资产阵地** | 沉淀粉丝、会员、老客资产 | 分层运营，提升高粘性用户占比 |

## 二、流量获取策略

### 用户进店意图分类

| 用户需求 | 购物预期 | 主要进店渠道 | 转化要点 |
|---------|---------|-------------|---------|
| **「看」** | 弱、线索模糊 | 短视频、直播、飞鸽会话 | 稳定优质内容，积极互动，定期消息触达 |
| **「逛」** | 强、线索模糊 | 商城推荐、商详页、橱窗 | 强化卖点，新人优惠，明确利益点 |
| **「买」** | 强、线索清晰 | 搜索、订单页面 | 优化商品名称，提升复访复购 |

### 流量入口运营动作

#### 短视频进店
1. **短视频挂载店铺组件**（效率更高）
   - 配置路径：短视频店铺组件
2. **置顶评论进店链接**
   - 适用：软性种草内容

#### 直播进店
1. 直播间配置进店入口
2. 主播口播引导进店（组合店铺利益点）
3. 直播间指示器跳转店铺

#### 搜索进店
1. 策划品牌搜索口令
2. 投放搜索品专
3. 优化店铺名称，搜索关联词

#### 商城进店
1. 确保商品满足商城推荐分发门槛
2. 积极提报频道活动（超值购、限时限量购、品牌馆）

#### 订单页面（老客路径）
1. 引导用户复购
2. 上新获取流量（上新标签在各入口明显展示）

## 三、客单价提升策略

### 货单价提升

#### 商品数量与信息维护
- 在售商品总数越多，全店动销越好
- 价格真实稳定，商城与直播间同价
- 商品上架后不频繁上下架

#### 店铺上新
| 维度 | 要求/效果 |
|------|----------|
| 新品定义 | 上架时间 ≤30 天的全新商品链接 |
| 定期上新效果 | 吸引老客复购，获得上新标签，各入口获得更多流量 |
| Tab装修门槛 | 有效商品数 ≥6，有效新品数 ≥3 |

### 单次购买件数提升

#### 货品分层策略
```
┌─────────────────────────────────────────────────┐
│                 货品分层模型                     │
├─────────────┬─────────────┬─────────────────────┤
│   新品      │   爆品     │      清仓款          │
├─────────────┼─────────────┼─────────────────────┤
│ 毛利高于大盘│ 转化率高   │ 库存周转             │
│ 提升成交    │ 引流主力   │ 获取流量             │
│ 新品Tab展示 │ 达人带货   │ 营销玩法             │
└─────────────┴─────────────┴─────────────────────┘
```

#### 流量场货品策略
- **直播场**：新品 + 爆品为主
- **中心场（商城）**：爆品 + 清仓货品，参与营销玩法

#### 分人群组货
- 粉丝客单价较非粉丝提升 **101%**
- 会员客单价较非会员提升 **119%**
- 新客：高价格力商品 + 货品组合拉新
- 粉丝/会员：重点推荐新品

#### 搭配组货工具
- **搭配购**：创建多商品搭配销售和优惠
- **分类页**：商品结构化展示

## 四、转化率提升策略

### 店铺停留时长

#### 店铺装修
- 有装修的店铺停留时长提升 **134%**
- 不同行业装修重点：
  - 头部商家/亲子生活：营销组件点击率高（优惠券、满减）
  - 个护行业：商品组件点击率高（榜单、爆款、热搜）

#### 装修方向
**基础装修**：店铺装修合格
**高阶装修**：
- 内容：店铺服务、店铺理念故事、卖家人格化
- 主题：首页聚合商品主题、店铺页与详情页串联

#### 平台背书
- **抖店排行榜**：经营能力认证，增强信任感
- 榜单类型：DFashion宝藏私服店铺榜、户外撒野店铺服饰榜等

### 下单转化率

#### 商品维度营销工具
| 工具 | 适用人群 | 说明 |
|------|---------|------|
| 限时限量购 | 全量用户 | 满足价格敏感且购物预期不明确场景 |
| 商品优惠券 | 全量用户 | 指定商品发放 |

#### 店铺维度营销工具
| 工具 | 适用人群 | 说明 |
|------|---------|------|
| 全店通用券 | 全量用户 | 店铺和直播间均可展示 |
| 搭配购 | 全量用户 | 多件商品搭配组合，一键下单享优惠 |

#### 人群维度权益
| 工具 | 适用人群 | 说明 |
|------|---------|------|
| 店铺新人券 | 新客 | 提升新人的成交转化 |
| 店铺粉丝券 | 店铺粉丝 | 直播间发放，仅粉丝可领 |
| 达人粉丝券 | 达人粉丝 | 合作达人直播间发放 |
| 会员开卡礼 | 会员 | 加入店铺会员领取 |
| 会员专享券 | 会员 | 老会员优惠券，提升复购 |
| 会员抽签购 | 会员 | 针对新品、联名款，提升商品热度 |

## 五、购买频次提升策略

### 店铺上新
- 满足用户"逛"的需求
- 新品 Tab 引导进店浏览和复购
- 服饰等强新品心智行业，购买意愿更强

### 营销活动
**活动 Tab**：
- 开启门槛：至少 7 个已上架有效商品 + 至少两类营销活动
- 价值：串联用户需求，完成商家营销和流量承接

### 用户关系维系

#### 沉淀新客为老客
- 设置店铺新人券等限时福利
- 售后服务、客服回访沉淀为粉丝/会员

#### 提高老客忠诚度
**粉丝、粉丝团、会员核心指标**：
- 下单转化率高于普通用户
- 店均停留时长高于普通用户
- 客单价及复购订单数明显高于普通用户

**运营方法**：
1. **关系沉淀**：用户成长体系 + 粉丝券/开卡礼
2. **触达与经营**：粉丝群、飞鸽消息、售后服务
3. **召回与转化**：会员 Tab、专享券、积分权益、复购券

## 七、直播运营策略

### 直播间进店配置
1. 配置进店入口（常规入口，点击即可进店）
2. 主播口播引导进店（组合店铺利益点）
3. 直播间指示器跳转店铺

### 直播节奏规划
- 日播：保证直播时长，积极与用户互动
- 周播节奏：周一二热销款，三四新品测款+粉丝召回，五六日上新品，大促后清仓
- 时间段：建议 7:00-24:00

### 直播货品策略
- 与商城差异化经营
- 直播场：新品 + 爆品
- 商城：单品 + 品牌/品类搭配组货

## 八、短视频运营策略

### 内容策略
- 日更：商家账号每日至少 10 条
- 内容类型：新品展示、种草、直播预热
- 新品为主：月均 40+ 条短视频

### 引流策略
1. **短视频挂载店铺组件**：图标明显，利于直接进店
2. **配置置顶评论进店链接**：软性种草引导

### 短视频与直播联动
- 短视频商品与直播强关联
- 短视频引流直播间
- 短视频带搜索词召回

## 十、供销平台（供应商操作指南）

### 平台定位
- 为供应商（品牌、工厂、供货商）和抖店商家建立的线上分销平台
- 入驻条件：限企业和个体工商户，公司成立 ≥1 年

### 核心概念
| 概念 | 定义 |
|------|------|
| 供应商 | 品牌方、品牌代理商、渠道商、工厂 |
| 分销品 | 供应商发布，供抖店选择 |
| 商品 | 抖店发布，供消费者选择 |
| 供货单 | 抖店与供应商产生交易的订单 |

### 发货流程
1. 绑定关系后，**供应商可打单发货，抖店不可**
2. 正确流程：**先系统打单发货，再操作实物发货**
3. 必须使用第三方 ERP 打单（消费者信息加密）

### 结算方式
- 担保交易
- 代销分账
