# Novel Creator - 全能小说创作引擎

融合多个优秀技能的核心能力，打造完整的小说创作工具链。

## 核心能力

| 能力 | 来源 | 功能 |
|------|------|------|
| 📁 项目管理 | novel-writing | 目录结构、状态追踪 |
| 🎭 设定管理 | novel-writing | 世界观、角色、规则 |

## 工作流程

### Phase 1: 开书初始化

```
用户: "我要写一本仙侠小说"
→ novel init 《书名》 --type 仙侠
→ 创建项目结构
→ 加载仙侠模板（可选）
```

**输出**：
- 项目目录已创建
- 默认设定模板已加载
- state.json 初始化

---

### Phase 2: 设定录入

```
用户: "主角叫李凡，16岁，资质平平但意志坚定"
→ novel setting character 李凡
→ 录入角色卡
→ 自动检测冲突
```

**角色卡模板**：
```markdown
## 李凡

**基础信息**
- 年龄：16岁
- 身份：青云门外门弟子
- 资质：丁等（平平）
- 性格：意志坚定、不屈不挠

**外在特征**
- 外貌：（待补充）
- 标志性动作：（待补充）

**内在驱动力**
- 核心目标：成为真正的修仙者
- 恐惧：被看不起、平庸一生
- 秘密：（待补充）

**角色弧线**
- 初始状态：自卑、渴望认可
- 成长方向：自信、强大
- 终局状态：（待规划）

**文风要点**
- 说话风格：简洁、直接
```

### Phase 5: 质量检查

```
用户: "检查第一章"
→ novel check 1
→ 伏笔检测（是否登记）
→ 冲突检测（是否违反设定）
→ 去AI味扫描
```

**去AI味检查清单**：
- [ ] "深吸一口气"
- [ ] "嘴角微微上扬"
- [ ] "眼神变得坚定"
- [ ] "心中涌起一股暖流"
- [ ] "无奈地摇了摇头"
- [ ] 形容词堆砌（连续3个+）
- [ ] 长句过多（连续30字+）

---

### Phase 6: 6维度评分

```
用户: "评估第一章"
→ novel eval 1
→ 6维度量化评分
→ 给出改进建议
```

**评分维度（总分100）**：

| 维度 | 分值 | 重点 |
|------|------|------|
| 情节架构 | 25分 | 逻辑、节奏、悬念 |
| 人物塑造 | 20分 | 立体度、一致性、成长 |
| 文笔质量 | 15分 | 精准度、流畅度、去AI味 |
| 世界观设定 | 15分 | 严谨度、细节、真实感 |
| 情感共鸣 | 15分 | 代入感、感染力 |
| 创新性 | 10分 | 题材、叙事、思想 |

**等级**：S(90+) | A(80-89) | B(70-79) | C(60-69) | D(<60)

## 伏笔追踪规则

**登记格式**：
```markdown
| 章节 | 伏笔内容 | 类型 | 预计回收章 | 状态 |
|------|---------|------|-----------|------|
| ch001 | 神秘老人路过 | 线索 | ch050 | 待回收 |
| ch003 | 玉佩发光 | 物品 | ch020 | 待回收 |
| ch010 | 师兄眼神闪烁 | 人物 | ch015 | 已回收 ✅ |
```

**预警机制**：
- 超过预计回收章3章 → 黄色警告
- 超过预计回收章10章 → 红色警告
- 卷末未回收 → 强制提醒

## 文风指南模板

```markdown
## 文风指南：仙侠热血风

### 叙事语气
- 简洁、有力、不拖沓
- 避免华丽辞藻堆砌
- 注重动作与心理的平衡

### 句式偏好
- 短句为主（60%+）
- 长句用于环境描写
- 对话干脆利落

### 禁忌词表
- 不要用：深吸一口气、嘴角上扬、眼神坚定
- 避免：很、非常、极其（用具体描写替代）

### 情感表达
- 内敛方式：用动作暗示而非直接描述
- "他握紧拳头" > "他感到愤怒"
```

## 特色功能

### 1. 智能上下文召回
写第N章时，自动召回：
- 相关角色设定
- 前5章摘要
- 未回收伏笔
- 读者反馈要点

### 2. 冲突预警
新设定录入时，自动检测：
- 与已有设定冲突
- 名称重复
- 能力体系矛盾

### 3. 去AI味引擎
写作后自动扫描并提示：
- 套路表达替换建议
- 句式节奏优化
- 形容词精简

### 4. 多模型协作
可选启用：
- MiMo写初稿（快速）
- Gemini逻辑审阅（严谨）
- Claude文学审阅（细腻）
- 飞书完整存档

## 使用示例

```
用户: 我想写一本都市重生小说
→ novel init 《重生之商业帝国》 --type 都市重生
→ 创建项目结构
→ 加载都市模板

用户: 主角叫陈风，35岁上市公司CEO，重生回18岁
→ novel setting character 陈风 --age 35→18
→ 创建角色卡
→ 检测冲突：无

用户: 规划前20章大纲
→ novel outline 1-20 "陈风重生，利用前世记忆白手起家"
→ 生成分章大纲
→ 建议伏笔：前世仇人、关键事件、商业机密

用户: 写第一章
→ novel write 1
→ 加载：陈风角色卡、重生模板、文风指南
→ 输出：3400字正文 + 2个伏笔登记

用户: 检查并评分
→ novel check 1 && novel eval 1
→ 伏笔检测：通过
→ 去AI味：发现3处建议修改
→ 评分：情节22/25 人物18/20 文笔12/15 世界观13/15 情感12/15 创新7/10
→ 总分：84分（A级）

用户: 同步到飞书
→ novel sync --feishu
→ 创建文档：https://open.feishu.cn/...
→ 上传：设定+大纲+第一章+评分
```

## 注意事项

1. **设定先行**：写正文前必须完成基础设定
2. **伏笔必有回收**：每个伏笔都要有回收计划
3. **文风一致**：每本书锁定一种文风
4. **定期评分**：每5章做一次综合评分
5. **冲突检测**：新增内容必须过冲突检测
